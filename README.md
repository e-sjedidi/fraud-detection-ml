# 💳 Détection de fraude bancaire (Machine Learning)

## Objectif
Détecter automatiquement les transactions frauduleuses en utilisant un modèle de Machine Learning.

## Techniques utilisées
- Python, Pandas, NumPy
- Machine Learning : Random Forest
- Visualisation avec Matplotlib et Seaborn
- Analyse de l'importance des variables

## Dataset
- Dataset de transactions bancaires (dataset public)
- Chargé directement depuis internet (Colab-friendly)
- Class imbalance géré automatiquement avec stratified split

## Résultats
- Classification report détaillé
- Confusion matrix graphique
- Top 10 features importantes identifiées
- Graphiques prêts à présenter

## Colab (probleme avec kaggle)
1. Ouvrir [Google Colab](https://colab.research.google.com)  
2. Créer un nouveau notebook  
3. Copier-coller le code du fichier `fraud_detection.py`  
4. Exécuter les cellules (toutes les librairies sont déjà incluses dans Colab)  
5. Les graphiques s’afficheront directement pour analyse

## Applications professionnelles
- Sécurité bancaire
- Prévention de la fraude
- Analyse des risques financiers
- Compétences démontrées : Machine Learning, data analysis, data visualization
